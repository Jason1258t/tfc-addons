# Debug Tools (`debug_tools`)

Отладочные команды для проверки сборки. Только ручная установка: `tfc addons install debug_tools`. Нужны права
оператора (2), игрокам не нужен. Логика только на сервере, поэтому ставится туда, где работает мир: хосту в папку игры
или на выделенный сервер.

| Команда                                            | Что делает                                                                    |
| -------------------------------------------------- | ----------------------------------------------------------------------------- |
| `/tfcdebug vein list [слово]`                      | все жилы из реестра: редкость, высоты; зелёные есть в биоме под игроком        |
| `/tfcdebug vein find <жила> [радиус] [сколько]`    | ближайшие центры жилы по сиду мира, чанки не генерируются. Координаты кликабельны |
| `/tfcdebug vein check <жила> [радиус] [сколько]`   | генерирует чанки у центров в подходящем биоме и считает настоящую руду         |
| `/tfcdebug ore <блок> [радиус]`                    | сколько блока в квадрате вокруг игрока, высоты, пример координат; чанки генерируются |

Радиус — в чанках: у жил 256 по умолчанию (до 1000), у `ore` 4 (до 32). `check` и `ore` работают по одному чанку или
центру за тик и пишут итог в чат и в лог строками `[tfcdebug]`.

`check` и `ore` меняют мир: генерируют чанки. Только в копии мира. Жилы появляются лишь в чанках, сгенерированных
после того, как жила попала в сборку: в уже посещённых чанках `check` покажет 0.

## Как это работает

Центр жилы TFC зависит только от сида мира и номера чанка: `VeinFeature.getVeinsAtChunk` (байткод TFC 4.2.9). Будет ли
там руда, решают биом (`BiomeGenerationSettings.hasFeature`, у TFC жилы идут через тег `tfc:in_biome/veins`) и порода:
жила заменяет только блоки из своего списка `blocks`, поэтому центр в неподходящей породе даёт 0 руды. `find` этого не
знает, `check` показывает породу в центре.
