# Аддоны «TFC Studio»

Свои моды для сборки TerraFirmaCraft RealWorld (Minecraft 1.21.1, NeoForge): электрика для Electro Energetics,
дизель, нагрев в IE, инструменты шахтёра и строителя, пиротопливо и фиксы сервера. Каждый аддон — своя папка
(`<имя>-mod/`) с проектом Gradle, карточкой сайта `addon.json`, иконками и скриптом выпуска.

Скачать готовые jar и почитать про каждый аддон — на сайте: https://tfc-plans-fd2c.web.app/addons. Программа `tfc`
ставит их сама (`tfc pull addons`).

Репозиторий подключён к сайту [tfc-plans](https://github.com/Jason1258t/tfc-plans) как папка `tools/` (git submodule):
сборка, проверка и выпуск — по [docs/addons.md](https://github.com/Jason1258t/tfc-plans/blob/main/docs/addons.md)
оттуда. История до выделения в отдельный репозиторий сохранена.
