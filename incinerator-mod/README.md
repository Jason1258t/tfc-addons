# Incinerator — мусоросжигатель

Блок `incinerator:incinerator` для сборки TFC Studio. Уничтожает всё, что в него попадает:

- **касание** — предмет, упавший сверху (верх на 1/16 ниже полного блока, как у воронки, — предмет оказывается в
  клетке блока, и `entityInside` его сжигает);
- **устройства** — блок отдаёт стандартную ёмкость предметов NeoForge (`Capabilities.ItemHandler.BLOCK`) с любой
  стороны: вставка в любую ячейку принимает всё и сжигает. Так к нему подключаются шлюзы и желоба Create, воронки,
  конвейеры IE. Кода Create аддон не использует.

**Гарь.** С каждого сожжённого предмета с шансом 15 % (`IncineratorBlockEntity.RESIDUE_CHANCE`) остаётся один
случайный предмет тега `incinerator:residue` — в сборке `tfc:powder/wood_ash`, `tfc:powder/charcoal`,
`tfc:powder/coke` (порошка каменного угля в сборке нет; тег можно дополнить датапаком). Гарь копится в 4 стопках
(ячейки 1–4 ёмкости, только на выход), лишняя пропадает. Забирать — шлюзом на выход, воронкой снизу и т. п.
Редстоун-сигнал (`powered=true`, верх — незерак без свечения) выключает гарь; жечь блок продолжает. Сломанный блок
роняет накопленную гарь.

Рецепт (при Create и Create: Connected): `PFP / ACA / PNP` — P железная пластина `#c:plates/iron`, F андезитовый
шлюз, A андезитовый сплав, C катализатор массового плавления, N незерак.

## Что проверено

1.0.0 (2026-11-13), `./test-server.sh` — NeoForge 21.1.251 + TFC 4.2.9, Create 6.0.10, Create Connected 1.3.2,
плоский мир:

- воронка с 64 булыжника → желоб Create → сжигатель: всё сгорело; гравий на андезитовом шлюзе на вход — сгорел;
  64 земли, брошенные сверху, — сгорели; андезитовый шлюз на выход выдал гарь, воронка снизу забрала гарь;
- 1000 предметов через ёмкость: гарь 151 и 134 в двух запусках (15,1 % и 13,4 %), виды примерно поровну;
- под сигналом (блок редстоуна рядом) 640 предметов — гари 0;
- `KEEP=1` перезапуск — гарь внутри сохранилась; `NO_MODS=1` (без TFC и Create) — грузится, гари нет (тег пуст);
- рецепт `incinerator:incinerator` загружен.

Модель смотрели рендером MCP (`model_render`), в клиенте не открывали.
