# Спрайты ComputerCraft

Оригиналы подготовлены в ImageGen. Образцы EE Extras — `network_transceiver` и `pocket_display`.
Антенна — стальной штырь на небольшой опоре с медным контактом. Матрица — тёмное стекло, корпус ABS,
три метки RGB и медный вывод. Игровые PNG уменьшены без сглаживания до холста 32×32 с прозрачными полями.
