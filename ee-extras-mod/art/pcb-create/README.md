# Верхняя панель адаптера Create

Оригинал: `panel-source.png`, встроенный imagegen, 18.11.2026.
Ориентир палитры: существующая текстура EE Extras `module_housing.png` и просмотренная модель `pcb_create_interface`.
Запрос: плоская квадратная панель в пиксельном стиле Minecraft, тёмный сине-зелёный металл, четыре крепления, два простых канала: медная ступенчатая аналоговая кривая и два зелёных логических контакта. Без букв, цифр, перспективы, свечения и декоративного шума.
Механическая подготовка: уменьшение NEAREST до 32×32, MAXCOVERAGE 16 цветов без дизеринга, непрозрачный RGB.
Результат: `textures/block/pcb_part/create_interface_panel.png`; `panel-preview.png` — увеличение без сглаживания.
Текстура используется только верхней гранью верхней крышки; корпус и контакты используют существующие текстуры EE/Create. Клиентская приёмка ожидает стенд.
