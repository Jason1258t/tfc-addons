# Компоненты ComputerCraft

Магнит и флакон электролита созданы через ImageGen, с образцами из EE Extras. Здесь хранятся оригиналы с прозрачностью. Для игры спрайты обрезаны по альфа-каналу, уменьшены до 28 пикселей по длинной стороне без сглаживания и размещены на прозрачном холсте 32×32.

- Магнит. Образец — `inductor`. Запрос: компактное тёмно-стальное кольцо с прозрачным центральным отверстием, серой верхней плоскостью и графитовыми боковинами. Один предмет на прозрачном фоне, простая форма, сетка 24–28 пикселей, 4–8 плоских цветов.
- Электролит. Образец — `battery_module`. Запрос: приземистый квадратный стеклянный флакон с бледным электролитом и тёмной крышкой в ракурсе три четверти. Один предмет на прозрачном фоне, простые плоскости, сетка 24–28 пикселей, 6–10 плоских цветов.
- Диффузор. Образец от игрока — динамик с бумажным конусом. Запрос: выделить неглубокий бумажный конус с центральным колпачком, убрать металлическую рамку и крепления, оставить широкие кремовые и бежевые зоны.
- Картридж. Образец от игрока — графитовый картридж с окном и контактами. Запрос: сохранить основные детали, упростить грани и сделать окно приглушённо-синим. Для обеих текстур дополнительным образцом стиля служил магнит.
