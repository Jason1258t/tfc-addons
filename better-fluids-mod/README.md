# Better Fluids

Аддон для жидкостных механизмов сборки TFC Studio. Для версии 1.0.0 нужны Minecraft 1.21.1, NeoForge 21.1.219 и Create 6.0.10. Установите jar на сервер и клиент.

## Железный резервуар

Одна секция вмещает 14 вёдер. Восемь железных пластин вокруг стеклянной панели дают одну секцию. Резервуары имеют квадратное основание до 3×3 и ограничение высоты от Create. Трубу можно подключить к любой секции. Окна переключаются ключом Create.

Поставьте секцию на верхнюю или нижнюю грань собранного резервуара. Если весь слой помещается и хватает секций, заполнится весь слой. При удержании Shift, нехватке секций или препятствии ставится только выбранная секция.

## Реализация и проверка

Тип сущности отделяет железные резервуары от баков Create в его `ConnectivityHandler`. В Create 6.0.10 `FluidTankBlockEntity` запрашивает ёмкость секции при создании хранилища, пересборке, чтении NBT и перераспределении жидкости. Миксин подставляет 14 000 мБ только для железной сущности. Рендерер и модели Create используются с отдельной палитрой железа.

- `./test-server.sh 'sleep 2' 'betterfluidstest build'` проверяет установку слоя 2×2 одним действием, расход четырёх секций, доступ к 112 вёдрам через верхнюю секцию и отдельный медный бак.
- `./test-server.sh 'sleep 2' 'betterfluidstest reload'` проверяет ёмкость и сохранение 112 вёдер воды после перезапуска.
- Оформление в клиенте и проверка крафта в мире сборки остаются за игровой проверкой.
