# Better Fluids

Аддон для жидкостных механизмов сборки TFC Studio. Для версии 1.5.1 нужны Minecraft 1.21.1, NeoForge 21.1.219+ и Create 6.0.10. Установите jar на сервер и клиент.

## Железный резервуар

Одна секция вмещает 14 вёдер. Восемь железных пластин вокруг стеклянной панели дают одну секцию. Секции соединяются по граням и образуют общий бак произвольной формы. Трубу можно подключить к любой секции.

Поставьте секцию на верхнюю или нижнюю грань. Если есть место и блоки, установка повторит форму соединённого горизонтального слоя. Если секций мало, они начнут достраивать слой от выбранного места. С зажатым Shift ставится одна секция.

Окна соседних секций сливаются: на прямой стенке бака стекло идёт сплошной полосой, стойки остаются только там,
где стенка кончается или поворачивает. Секция без окна, другой высоты или фасонная прерывает полосу.

Ключ Create на боковой грани размыкает текущие соединения выбранной секции. Секция остаётся на месте с находящейся в ней жидкостью. При установке новых секций они продолжат выбранную группу и сохранят её границу с соседним баком. Повторный клик открывает связи, закрытые на этой секции. Верхняя и нижняя грани по-прежнему переключают окно.

## Хранение и переход с 1.0.0

Жидкость хранится в секциях. При разъединении каждая группа сохраняет содержимое своих секций. Для расчёта вместимости и перекачки учитываются загруженные секции. Если соединить баки с разной жидкостью, жидкость сохраняется, а долив блокируется до опорожнения лишнего типа.

Резервуары 1.0.0 переходят на хранение по секциям после загрузки всех своих блоков. Номера и рецепты блока прежние.

## Проверка

- `./test-server.sh 'sleep 2' 'betterfluidstest build' 'betterfluidstest freeform'` проверяет слои 2×2 и Г-образной формы, расход секций, 112 вёдер в баке 2×2×2, отсоединение перемычки ключом и продление отдельного бака вплотную к старому.
- `./test-server.sh 'sleep 2' 'betterfluidstest reload' 'betterfluidstest split_reload'` проверяет жидкость и связи после перезапуска. Мир с заполненным баком 1.0.0 также проверен через `reload` после обновления.
- `./test-client.sh` строит баки разных форм в плоском мире и снимает кадры сверху, снизу и вблизи (`run/screenshots/bf-*.png`): крышка и дно у рядов шириной в один блок, сплошное стекло стенки. `EXTRA="sodium-neoforge"` добавляет Sodium из сборки.

### Фасонные секции (1.2.0)

На камнерезе пустую секцию можно превратить в любую другую форму в отношении 1:1.
Полублок и секция с четырьмя скосами 45° вмещают по 7 вёдер, четвертная секция — 3,5 ведра.
Полублок ставится горизонтально на верхнюю или нижнюю грань и вертикально на боковую.
Они занимают по одной позиции в сетке и соединяются с соседними секциями в общий бак.


## Жидкостный интерфейс

Поставьте интерфейс на любую грань бака Create или Better Fluids. Нажмите по интерфейсу ПКМ с ведром,
канистрой IE или другой ёмкостью с поддержкой жидкостного API NeoForge. Ёмкость набирает подходящую жидкость
из бака. Рецепт — жидкостная труба Create и четыре железных листа.

Интерфейс обращается к жидкостной capability грани бака. В Create 6.0.10 собственный обработчик
`FluidTankBlock.useItemOn` ограничивает ручной перелив обычного бака творческим режимом. Интерфейс даёт
отдельную точку набора в выживании. На стенде `WITH_IE=1 ./test-server.sh 'betterfluidstest tap'` проверяет
ведро и канистру IE на шести гранях обоих баков, расход жидкости и снятие интерфейса при разрушении бака.
