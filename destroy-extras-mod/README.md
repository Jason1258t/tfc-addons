# Destroy Extras

Каркас будущего аддона химических машин для dev-задачи #22. **Версия 0.1.0 не предназначена для игроков:** игровых
блоков, предметов, рецептов и химической прогрессии в ней пока нет.

По согласованной архитектуре:

- Destroy остаётся источником молекул, смесей, реакций и существующих машин;
- Destroy Bridge предоставляет TFC fluid adapter, EE process driver и атомарную многопортовую операцию;
- Destroy Extras будет владеть только недостающими машинами, включая мембранный электролизёр и травильную ванну;
- платы и их редактор остаются в EE Extras;
- новые отдельные fluid type для H₂, Cl₂, NaOH, HCl и других уже представленных в Destroy веществ не создаются.

## Сборка и проверка

```bash
export JAVA_HOME="$HOME/.gradle/local-tools/jdk21/Contents/Home"
./gradlew build --console=plain
./test-server.sh
```

Общий стенд находится в `../destroy-bridge-mod`: там зарегистрирован devtest-мод и команды `/destroytest`. Этот скрипт
просто передаёт ему аргументы. Профили `minimal`, `thermal`, `sable`, сохранение мира `KEEP=1` и результаты описаны в
[README моста](../destroy-bridge-mod/README.md).

Чистая сборка и загрузка пустого runtime-аддона вместе с мостом проверены на dedicated server. M1 моста также проверен;
M2 — компактный контроллер, мембрана, три порта, первый рецепт, JEI и русские статусы — ещё не реализован.
